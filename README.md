# PROG5121 QuickChat

## Part 1
The application allows a user to:

- Register using a username, password and South African cellphone number.
- Validate username formatting.
- Validate password complexity.
- Validate cellphone number formatting.
- Log in using the registered username and password.

## Part 2
After logging in successfully, the user can access QuickChat.

The application allows the user to:

- Choose how many messages they want to enter.
- Send messages.
- Validate recipient cellphone numbers.
- Limit messages to 250 characters.
- Generate a unique 10-digit message ID.
- Generate a message hash.
- Send, disregard or store a message.
- Store messages in a JSON file.
- Display the total number of messages sent.
- Quit the QuickChat application.

## Testing
JUnit tests are included for:

- Login functionality.
- Username validation.
- Password validation.
- Cellphone validation.
- Message length.
- Recipient validation.
- Message ID generation.
- Message hash generation.
- Sending messages.
- Discarding messages.
- Storing messages.
- JSON file creation.
